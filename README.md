# Cristal Traductor

Traductor de pantalla en tiempo real para Android. Pones un "cristal" sobre cualquier parte de la pantalla y el texto que queda debajo aparece traducido al español mientras lees y haces scroll. Ideal para leer fanfics, libros y páginas web en otros idiomas.

Todas las versiones: [Releases](https://github.com/chavezdeleonbryan-cmd/cristal-traductor/releases)

## Qué hace

- Traduce **en el momento** el texto que está debajo del cristal, sin tomar capturas.
- **No bloquea la pantalla**: tus toques atraviesan el cristal, así que puedes hacer scroll, pasar página y tocar enlaces con normalidad.
- El cristal se puede **mover** (⠿ Mover), **cambiar de tamaño** (↕: 35 %, 50 %, 75 % o pantalla completa), **pausar** (⏸) y **cerrar** (✕).
- Detecta solo el idioma: inglés, japonés, italiano, francés, portugués, coreano, chino y muchos más.

## Privacidad

- La traducción se hace **dentro del teléfono** (Google ML Kit). Lo que lees **no se envía a ningún servidor** y **no se guarda**.
- Solo usa internet la primera vez, para descargar cada idioma (unos 30 MB por idioma).
- Usa el permiso de **accesibilidad** únicamente para leer el texto que queda bajo el cristal y dibujar la traducción encima.
- El código completo está en este repositorio para que cualquiera lo revise. El APK se compila automáticamente desde este código con GitHub Actions.

## Instalación

1. Descarga el APK desde el enlace de arriba y ábrelo. Si Android lo pide, permite que tu navegador instale apps desconocidas.
2. Abre **Cristal Traductor**.
3. Toca **Abrir info de la app** → menú ⋮ (arriba a la derecha) → **Permitir ajustes restringidos**. (En Android 13 o más reciente; si no aparece, sigue al paso 4).
4. Toca **Abrir Accesibilidad**, busca **Cristal Traductor** (a veces en "Apps instaladas" o "Servicios descargados") y actívalo.
5. Opcional: con Wi-Fi, toca **Descargar idiomas ahora**.

Requiere Android 8.0 o más reciente.

## Limitaciones

- Funciona con apps que muestran texto real: navegadores (Chrome, etc.), AO3, Wattpad, FanFiction, lectores de libros y la mayoría de apps.
- **No traduce la mayoría de juegos** ni texto dentro de imágenes, porque ahí el texto es parte del dibujo.
- Al hacer scroll muy rápido, la traducción tarda una fracción de segundo en aparecer.
